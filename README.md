# Pasanauri

Multilingual restaurant menu built with Next.js, TypeScript, Tailwind, shadcn, next-intl, and Zustand.

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
```

See [application documentation](DOCUMENTATION.md), [architecture](docs/architecture.md), [requirements](docs/productRequirements.md), and [data integration](docs/placeholderData.md).

# Security boundaries

Public menu and gallery data are readable without authentication. Locale routing and branch selection do not authorize operations.

PWA manifests and icon assets contain public branding only. Standalone display changes no authentication or authorization boundary. No service worker, offline response cache, or background push subscription is registered. Cart, checkout, order snapshots, contact fields, and notes remain outside any offline cache.

Zustand state and localStorage are untrusted browser data. Cart restoration validates records and migrates older selections. Server rendering never shares customer cart state. Cart lines, appearance, and the notification reminder dismissal preference persist. Contact fields remain in form memory and are not transmitted or saved.

Checkout copies selections and an optional trimmed note of at most 500 characters into browser session memory and clears the local cart without a server mutation. The shared note schema validates both the form and store boundary. Notes may contain private information and must remain out of localStorage, browser notifications, logs, and public caches. Contact fields are never copied into order snapshots. All preview records are untrusted, temporary, and nonauthoritative.

Seeded pending, confirmation required, courier on the way, declined, and delivered records and their local ten second transition are fixtures. The courier example is not evidence of verified payment or dispatch. Customer reconfirmation never changes an order to onTheWay. Customer reconfirmation only changes a guarded local display state. It neither authorizes payment nor dispatches a courier. Pending delivery costs remain excluded from totals until a sample confirmation quote exists. Login provides no authentication. No database, payment provider, or live order processing is configured. No protected staff surface is introduced.

Persistent in app status cards and the confirmation tab dot remain available regardless of platform permissions. Confirmation transitions do not add a duplicate toast. A sound is attempted only using an audio context initialized by user interaction. Checkout completion offers a permission prompt. Native permission is requested only by explicit Allow or Ask again controls, with feature and secure context checks. Not now stays in page memory through a document attribute. Do not show again stores only a reminder dismissal boolean in localStorage, with a document attribute fallback when storage is unavailable. This preference changes no native permissions or order state. Native denials remain browser owned, and blocked retries explain browser specific settings instead of claiming permission was granted. Browser detection uses the user agent locally for help content only, without storage or transmission. Help remains within the page with a decorative pointer toward the browser controls. The pointer cannot access or interact with native browser chrome. Notification content contains only order identity and a request to review details. Never include contact fields, addresses, or notes. Unsupported or denied browser notifications must not block order interaction. No push subscription, background service worker, or external messaging is configured.

Future acceptance and decline operations must authenticate staff and authorize the target order. Server operations must bind delivery quotes and final totals to that order and customer. Confirm payment through a trusted provider boundary before courier dispatch or kitchen preparation, and make those side effects idempotent. Scope customer status, decline reasons, and tracking access to the owning customer. Validate external provider responses and webhook authenticity before updating order state.

Before introducing protected operations, authenticate the actor, authorize the exact operation and target, validate inputs on the server, and calculate prices and availability from trusted records. Keep secrets server only, exclude customer information from public caches and logs, and verify external webhook signatures when relevant.
